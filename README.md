## MobiMall 移动端 H5 商城

手机浏览器里能逛能买的一套完整商城流程，专注小屏适配、触摸手势与端到端下单闭环。

在线体验（手机直接打开，不用连 WiFi）：`https://stream-chat-59652.app.workbuddy.host/?sharecode=LLFFCYHB56`

### 项目架构

本项目是一个完整的前后端分离项目，包含三个部分：

```
MobiMall/
├── src/          # 前端页面与组件（Vue 3 + Vite）
├── server/       # 后端 API（Node 原生 http，零第三方依赖）
└── scripts/      # 数据生成与图片处理脚本
```

### 技术栈

| 层级 | 技术 |
|---|---|
| 前端 | Vue 3（组合式 API + `<script setup>`）+ Vite + vue-router + Pinia |
| 样式 | 原生 CSS + CSS 变量，不引 UI 库 |
| 后端 | Node.js 原生 `http` 模块，零第三方依赖 |
| 存储 | JSON 文件放在项目自己的 `data/` 目录，自包含可拷走 |
| 图片 | 后端 `/api/img` 实时代理（域名白名单 + 内存缓存），本机不落盘 |

### 数据来源

商品数据分两层，优先用实时层，拿不到自动降级：

- **实时层（默认）**：后端启动时与每隔 5 分钟，从公开测试接口 DummyJSON 拉取完整商品列表（191 件），标题、价格、库存、评分、图片均为图源真实数据，图文天然一致；中文搜索做了中英文词表映射（搜"耳机"可命中 headphones）。启动时加 `MOBI_LIVE=0` 可关闭。
- **兜底层**：`npm run seed` 生成的 36 件本地商品，实时层完全不可用时自动启用，保证断网也能演示完整流程。

### 功能特性

#### 首页

- 吸顶搜索框，输入防抖 300 毫秒后才发请求

- 轮播图（手写，自动播放 + 手势滑动 + 无缝衔接）

- 六宫格分类入口，窄屏（≤320px）自动降为三列

- 排序切换：综合 / 销量 / 价格升 / 价格降 / 最新

- 两列商品瀑布流，JS 按列高分配，不用 CSS 多列

- 下拉刷新：三态文案（下拉可以刷新 / 松手立即刷新 / 正在刷新…）

- 上拉加载更多：滚到底自动翻页，到底显示"没有更多了"

#### 分类页

- 左侧竖排分类栏 + 右侧商品列表，形态与首页刻意区分

- 切换分类时列表回到顶部并重新请求第一页

#### 搜索页

- 防抖搜索、历史记录、热门词

- 搜不到时显示空态，不是白屏

#### 商品详情

- 图片轮播，切换规格时价格实时变化

- 规格选择（按钮上直接标加价）、数量步进器，到库存边界时按钮置灰

- 商品参数、详情描述长图

- 加入购物车 / 立即购买，底部操作栏避开 iPhone 底部横条

#### 购物车

- 勾选、改数量、删除、全选、实时合计

- Pinia 管理状态并持久化到 localStorage，刷新不丢

- 底部 Tab 角标实时反映件数

#### 下单与结果

- 收货信息表单：失焦即校验，报错为中文文案

- 提交后跳结果页，展示订单号、收货信息、实付金额

- 金额由后端用商品价格重算，不采信前端传值

#### 我的

- 设备档位与降级依据展示（CPU 核数 / 内存 / 像素比 / 省流模式）

- 安装到桌面（PWA）、清空购物车

#### 移动端适配与性能

- `rem` 基准 `calc(100vw / 3.75)`，375px 屏上 1rem = 100px，超过 480px 封顶

- `clamp()` 流式字号，`100dvh` 解决地址栏吞高度

- `env(safe-area-inset-bottom)` 避开 iPhone 底部横条

- 可点区域最小 44px，所有 `:hover` 都补 `:active` 触摸反馈

- 图片懒加载（IntersectionObserver 提前 300px）+ 占位渐变 + `aspect-ratio` 固定坑位，CLS 为 0

- 低端机自动降级：核心数少、内存小、开了省流模式或系统开了"减弱动效"时，关掉毛玻璃与渐变动画

### 后端 API 文档

#### 商品模块

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/products` | GET | 商品列表。参数：`category`（all / digital / apparel / home / food / beauty / sport）、`keyword`、`sort`（default / sales / price-asc / price-desc / new）、`page`、`pageSize` |
| `/api/products/:id` | GET | 商品详情，含规格、参数、图片数组 |

#### 分类与轮播模块

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/categories` | GET | 六个分类（id + 名称 + 图标） |
| `/api/banners` | GET | 首页轮播图列表 |

#### 图片模块

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/img?u=图片地址` | GET | 图片代理。只放行白名单域名，带 5 分钟内存缓存、同地址并发去重与失败重试 |

#### 订单模块

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/orders` | POST | 提交订单。请求体 `{ items, address: { name, phone, address } }`，服务端二次校验并自行重算金额，返回订单号 |
| `/api/orders/:no` | GET | 按订单号查询订单详情 |

#### 健康检查

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/health` | GET | 服务状态、商品件数、订单数、实时数据源状态 |

### 本地部署

1. `npm install` —— 安装依赖，只做一次
2. `npm run seed` —— 生成 36 件兜底商品数据与界面用图（6 个分类图标 + 3 张轮播 SVG），只做一次，离线可跑
3. `npm run serve` —— 窗口一：启动后端，端口 3002
4. `npm run dev` —— 窗口二：启动前端，端口 5174，浏览器打开 `http://localhost:5174/`

打包模式（一个窗口，适合给手机看）：

```bash
npm run build
npm run serve   # 后端同时托管 dist 与 /api，打开 http://localhost:3002/
```

真机验收：电脑与手机连同一 WiFi，`ipconfig` 查电脑 IPv4，手机浏览器打开 `http://电脑IP:3002/`（打包模式）或 `:5174/`（开发模式）。

可选：安装到手机桌面（PWA）。Android 用 Chrome/Edge 的「添加到主屏幕」，iOS 必须用 Safari 的「添加到主屏幕」，微信内置浏览器会被拦。

常用环境变量：

| 变量 | 作用 |
|---|---|
| `MOBI_LIVE=0` | 关闭实时商品层，只用本地 36 件兜底数据 |
| `MOBI_DELAY=0` | 关闭接口人为延迟（默认 120ms，用于看清加载态） |
| `PORT` | 后端端口，默认 3002 |
